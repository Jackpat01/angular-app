JWT Claims (Replaces Session Variables)

These claims come from your JWT token and replace old ASP.NET session variables.

Claim Value Old Pattern
email {{ userClaims.email }} Session["Email"]
role {{ userClaims.role }} Session["UserRole"]
company {{ userClaims.company }} Session["CompanyName"]
provider {{ userClaims.provider }} Session["ProviderType"]
sub {{ userClaims.sub }} Session["UserId"]
How to Use JWT Claims (Code Examples)
Method 1: Use Observable (Reactive)
this.authService.userClaims$.subscribe(claims => {{'{'}
  console.log(claims.email);
  console.log(claims.role);
  console.log(claims.company);
{'}'})
Method 2: Get Synchronously
const claims = this.authService.getClaims();
const email = claims?.email;
Method 3: Get Specific Claim
const userRole = this.authService.getUserRole();
const company = this.authService.getCompany();
const customValue = this.authService.getClaim('provider');
Method 4: Use UserService Helpers
const email = this.userService.getUserEmail();
const role = this.userService.getUserRole();
const company = this.userService.getCompany();
